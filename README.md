# Jacqui Email — application de bureau

Installateurs de Jacqui Email pour macOS (Apple Silicon et Intel), Windows 64 bits et Linux 64 bits.

Téléchargement : https://jacqui.email/#telecharger

Ce dépôt contient uniquement les installateurs et les signatures des mises à jour. Aucun code source privé ni donnée utilisateur.

Sur Mac, ouvrez le DMG puis glissez Jacqui Email dans Applications. Les mises à jour se recherchent dans Paramètres → Application et mises à jour. Elles conservent le compte, les réglages et les données locales.

La signature des mises à jour est active. Les certificats de distribution Apple et Windows ne sont pas encore configurés : un avertissement du système peut apparaître à la première installation.
